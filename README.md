# 微信小程序灵感库（自部署版）

给年轻人做的微信小程序 / 工具灵感库：派对游戏、年轻人热门、实用工具
三类。每个点子都写清玩法、为什么推荐（点名真实海外原型）、怎么赚钱、
主体与资质（个人可做 / 需企业主体 / 需资质）、以及风险与注意。

本项目是托管空间的独立实现，不依赖任何托管平台，Node 20+ 就能跑，
零外部依赖。数据库是 SQLite，库为空时自动导入 `data/ideas-seed.json`
的 66 条种子（30 条策划 + 12 条已抓取 + 24 条海外）与 2 批抓取记录。

## 功能

- 灵感列表：内容全部写在卡片上，不用点开详情；手机 2 列、电脑 3 列；
  分类栏单行横滑；搜索、分类、主体筛选、只看未看 / 只看已看 / 只看收藏
- 每个点子：标题、卖点、玩法、为什么推荐、怎么赚钱、风险与注意、
  主体与资质说明、难度、抓取日期（新抓取的带标记）
- 收藏、状态（想做 / 评估中 / 已立项 / 先放下）、点开卡片自动标已看
  （变淡 +「已看」标记）、「点我，来一个新的」抽一条未看的（本轮不重复）
- 抓取记录：按批次列出每次抓取的时间、新增数、标题，点「只看这批」
  可单独筛出来；抓取到的卡片带「新抓取 · 日期」
- 右下角 `+`：点开向上展开「获取灵感 / 加个灵感」；标题旁也有小字
  「获取新灵感」，不显眼
- 定时抓取：见 `crons/auto-fetch.md`，默认一天 4 次、每批 12 条

## 怎么跑

```bash
npm install   # 零依赖，实际上什么都不用装；无网络也能跳过这步
npm start     # 默认 http://127.0.0.1:3000
```

环境变量（见 `.env.example`）：

- `PORT`：默认 3000
- `DATABASE_PATH`：默认 `./data/app.db`
- `FETCH_TIMES_PER_DAY`：默认 4（一天抓几次）
- `FETCH_BATCH_SIZE`：默认 12（每批抓几个）
- `MODEL_API_BASE_URL` / `MODEL_API_KEY` / `MODEL_NAME`：模型 API
  （OpenAI 兼容接口）。三项缺任何一项，抓取都会跳过、绝不编造灵感。

数据库在 `./data/app.db`，已内置 66 条种子。备份 = 直接复制这个文件。
`.gitignore` 已排除 `data/app.db` 与 `.env`——库内设置里的模型 Key
只存库文件里，不要提交、不要发公开渠道。

## Docker 部署（推荐，只绑局域网）

```bash
cp .env.example .env   # 按需填模型 API 与抓取频率
docker compose up -d
```

`docker-compose.yml` 只绑局域网示例地址 `192.168.1.10:3000`，请改成你
NAS / 服务器的局域网 IP，**不要写 `0.0.0.0`、不要做端口转发、不要
暴露公网**。浏览器打开 `http://192.168.1.10:3000` 即可。
数据目录 `./data` 已映射为卷，备份 = 复制卷里的 `.sqlite` 文件。

## 定时抓取（一天 4 次够不够？）

够。默认一天 4 次、每批 12 条，一天最多新增 48 条，去重后实际会少
一些。灵感是「挑」出来的，不是越多越好：一天 48 条新点子，一周就
是 300 多条，根本看不完。建议先按默认跑一周，如果觉得太多，改成
一天 2 次、每批 8 条；觉得不够再往上加。改法见 `crons/auto-fetch.md`。

来源说明：灵感不是从网站抄来的，也不是爬虫抓的。它是模型根据已知
的真实海外产品（如 Gartic Phone / BeReal / Yuka / Splitwise 等）
生成的中文点子，每条都要点名海外原型、写清为什么推荐、并附风险。
生成前读库里全部标题去重，生成后按标题归一化再去重一次；每批至少
5 条点名海外原型、至少 6 条通过校验才入库，否则整批丢弃。
没有配模型 API 时，抓取只记一条任务（连同完整提示词一起保存），
不入库、不编造灵感。

## 接口（POST /api/:action，JSON）

列表与查看：`listideas`、`getstats`、`listfetchlog`、`nextidea`；
标记：`togglefavorite`、`setstatus`、`markseen`；
增删：`addidea`、`deleteidea`（只有自己加的能删）；
抓取：`fetchnewideas`、`getfetchstatus`、`getfetchsettings`、
`savefetchsettings`、`seedcatalog`。

## 个人虚拟支付新规（2026-11-13 核对，腾讯官方文档）

微信已向个人主体小程序开放虚拟支付，无需注册公司。条件：服务类目
含「工具」、完成小程序认证+备案、月支付限额 10 万元（全终端合计），
仅限虚拟商品/数字服务（功能解锁、会员天数、AI 次数包、游戏道具、
课程等）；安卓费率 1%（T+3 到账），iOS 走苹果 IAP 佣金 12%
（约 45–60 天）。卖实物、做电商仍需个体工商户/企业主体 + 普通微信
支付；需办电信业务资质的服务（电子邮件、语音信箱、信息发布平台、
信息搜索查询等）不在开放范围。

按这条规则重标后的种子（2026-11-13）：个人可做 47 条、需企业主体
13 条、需资质 6 条。真正翻过来的只有 2 条——AI 抠图/老照片修复
（id 29，纯工具按次付费）、桌面照片小组件闺蜜版（id 52，仅限双人
私密工具形态）；另有 12 条个人项的收费说明从「收费需企业主体」
改成「个人虚拟支付可收」，19 条企业/资质项补了一句防误解备注
（实物、社交、UGC、版号、食品、招聘、占卜等，个人虚拟支付都绕
不过）。没有因为「能个人收钱」就把所有东西都翻成个人。

## 数据说明

- 种子：66 条（派对 20、年轻人 22、工具 24），其中 54 条带风险说明，
  12 条已抓取（ids 31–42）的风险在托管版里就是空的，这里如实保留为空、
  卡片上不显示风险段；以后新抓的强制带风险。
- 抓取记录种子：2 批，各 6 条（ids 31–36、37–42）。
- 时间戳字段均为 Unix 毫秒整数；`subject` 取值 personal / enterprise /
  license；`status` 取值 want / evaluating / started / dropped。

## 安全提醒

- 只监听局域网地址，不要暴露公网；没有管理员口令门，内网 + 不暴露
  就是保护。
- 模型 API Key 只放 `.env` / 环境变量，数据库文件不要发公开渠道、
  不要进公开仓库、不要发群里。
- 灵感里写的主体与资质、风险只是参考，立项前以微信平台最新审核
  为准；占卜、短剧、招聘、食品这类高风险类目尤其要先核对资质。
